# The Bath-Time Kraken

Entry for make.fun bounty **ai-excited-01 — "Make the AI judge excited"**.

A giant handmade crochet octopus bursts out of a small bathtub, yarn
tentacles grabbing rubber ducks while water splashes everywhere in the
warm sunset light. Funny, epic, and impossible to ignore.

## How it works

`main.py` (Python 3.13, no dependencies, no network) copies the bundled
`entry.jpg` to `/output/entry.png`. Every run writes the same bytes.

## Files

- `main.py` — the entry program
- `entry.jpg` — the image (1024×1024, JPEG)
- `LICENSE` — MIT
